# AngstremTest
>Это простой чат через WebSocket, для общения 2 и более пользователей

## Запуск
Для локального запуска приложения необходимо установить зависимости с ```npm i```, а также убедиться, что у вас установлена подходящая версия @angular/cli. Подходят версии 19+. 
Запустить через ```npm start```.

## Запуск сервера
Для локального запуска сервера понадобится установить репозиторий - . В README.md репозитория инструкция по запуску
